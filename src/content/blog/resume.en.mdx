### Town Pass Assistant — Honorable Mention, Taipei CodeFest 2026

- Built the MVP as MCP tools driven by Claude, then moved to direct function calls: 16 read-only tools over Town Pass services and open data, no server needed.

### Testa — online exam system for a school admission exam

_Java · Spring Boot · Vue · PostgreSQL · Docker_

- Built solo, from authoring and sitting the exam to proctoring, grading and publishing results; deployed on the school's VM and heading into an on-site rehearsal.
- Timing, submission and grading happen only on the server, and papers sent to candidates carry no answers; essays are graded anonymously by one or more teachers.
- Verified on production images with 300 candidates at once (p99 12 ms) and a full exam with no Internet.
- Optional AI import of old papers: a local 4B model drafts, code reads the answers from the file, tested on national exam papers.

### LabSlot — computer-lab booking system for a school

_Java · Spring Boot · React · SQLite · Docker_

- Built solo and deployed on the school's own server, now live; not a line of the school's existing systems was changed.
- Timetables and roles are read from the school database read-only, and credentials are forwarded to the school's sign-in; no school password is stored.
- A partial unique index in the database prevents double bookings; daily backups, with the restore rehearsed before launch.

### Agora-AI — campus AI assistant

_FastAPI · Next.js · Docker · SQLite · Gemini API_

- Reverse engineered the undocumented school system into 10 agent tools that answer natural-language questions about timetables, grades, attendance and leave.
- Containerized with Docker and deployed to a school VM through Cloudflare Tunnel; paused while I rethink the scope.

### Breakfast shop ordering system

_Next.js · Drizzle ORM · SQLite · LINE Messaging API_

- Scan a QR code to order; order status is pushed to the owner over LINE in real time.
- Orders modeled as a state machine and synced over SSE; nine tables in Drizzle ORM, with snapshots so menu edits never alter past orders.

### Girls Band Shot — subtitle screenshot search

### Build The Cat Gunner — Roblox 遊戲

_Luau · Rojo · Wally · Lune · react-lua_

- 一人開發並自行發行，2026 年 10 月上線；腳本、企劃、UI、數值平衡、投廣告與上線後數據分析都自己做。
- 伺服器權威架構：client 只送意圖，每個 remote 都檢查頻率、型別、所有權與餘額。
- 36 個純邏輯模組配 39 份 Lune 測試。

### 城市通安心助手 — 2026 臺北城市通微服務大黑客松佳作

_TypeScript · Vue · MCP · zod · Vitest_

- 負責提案發想、agent 設計和工具串接，五人團隊獲佳作。
- 先用 MCP 接 Claude 寫出 MVP，再改成直接函式呼叫，把台北通服務與開放資料包成 16 支唯讀工具，不需要 server。
- 提出共用服務工具庫的方向，讓新服務不用逐一手動串接；團隊照這個方向重構。

### Testa — 學校招生考試的線上考試系統

_Java · Spring Boot · Vue · PostgreSQL · Docker_

- 一人開發，從出題、考試、監考、閱卷做到公布成績；功能完成，準備到校內演練。
- 計時、交卷、批改只在伺服器做，送給考生的試卷不含答案；申論題由一到多位老師匿名評分。
- 在正式環境的映像檔上驗過 300 人同時作答（p99 12 ms）與斷網考完一整場。

### LabSlot — 學校的電腦教室借用系統

_Java · Spring Boot · React · SQLite · Docker_

- 一人開發並部署在校內伺服器，已上線；學校原本的系統一行都沒改。
- 課表與身分從學校資料庫唯讀讀取，帳密轉送學校登入系統驗證，不存任何學校密碼。
- 用資料庫的部分唯一索引擋重複借用；每天備份，還原流程上線前實際演練過。

### Agora-AI — 校務 AI 助理

_FastAPI · Next.js · Docker · SQLite · Gemini API_

- 逆向沒有公開文件的校務系統，包成 10 個 agent 工具，用自然語言就能查課表、成績、缺勤與請假。
- Docker 容器化，透過 Cloudflare Tunnel 部署到學校 VM；目前暫停，重新規劃範圍。

### 早餐店點餐系統

_Next.js · Drizzle ORM · SQLite · LINE Messaging API_

- 掃 QR code 點餐，訂單狀態即時透過 LINE 推給店主。
- 訂單用狀態機建模、SSE 同步前端；Drizzle ORM 設計 9 張表，訂單存快照，改菜單不影響歷史紀錄。

### 一句一幀 — 台詞截圖搜尋

_Next.js · Python · EasyOCR · ffmpeg_

- 用 OCR 建立字幕索引，跨三部作品搜尋台詞對應的畫面。
- 改成 ffmpeg 即時生成加 LRU cache，圖片儲存從 4 GB 降到 0。
